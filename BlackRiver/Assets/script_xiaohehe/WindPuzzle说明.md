# 序章3风帆机关

场景已绑定脚本，可直接运行。初始向左，在转经筒已有的 Trigger 内按 F，每次切换一个方向：左 → 下 → 右 → 上 → 左。

- `风帆` 根物体上的 `WindSailController` 管理四个风帆子物体和四个风区，使用显示/隐藏切换，没有修改物体旋转角度。
- `风/左、下、右、上` 各挂 `WindPushZone` 和一个 BoxCollider2D Trigger。选中对应方向物体，使用 Edit Collider 可以调整风的作用范围。方向物体隐藏时，对应风区也关闭。
- `转经筒0.1_0` 上的 `PrayerWheelInteraction` 已引用原有交互 Trigger，另一个实体碰撞体仍用于阻挡角色。F 使用项目现有的旧输入 API。
- 箱子脚底锚点在有效风区内时，沿风向逐格移动，遇到缺失格、禁止移动格或其他箱子停下。即使停下，只要还在风区内就不能手推；切换方向后，不再受风的箱子恢复手推。切换发生在移动途中时，会先走完当前一格。
- `PushBox.moveDuration` 调整每格移动时间，玩家推动与风推动共用此速度。
- 只要箱子的脚底锚点处于当前有效风区内，角色就不能从任意方向推动该箱子；风区外的箱子不受这条限制，风向本身不改变手推判定。
- `PushGridCell.centerOffset` 是网格中心相对物体的位置，序章3已按原有 Trigger 的 Offset 对齐。默认零偏移保留其他场景原有定位。
- 普通箱和特殊箱均受风，`isSpecialBox` 和原有 `PushWinTrigger.onWin` 胜利机制继续生效。

当前初始摆放中，特殊箱已经在左侧最末格，普通箱紧挨其右侧，所以默认左风不会让两箱继续左移。切换风向后，只有不在当前有效风区内的箱子才可继续手推。
